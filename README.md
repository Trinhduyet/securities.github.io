# Securities Engineering

Tài liệu học từ **Kinh tế học → Tài chính → Chứng khoán → Core Securities Engineering** dành cho backend engineer muốn hiểu sâu nghiệp vụ của công ty chứng khoán.

> Mục tiêu: đi từ “backend developer biết finance” đến “engineer hiểu core securities”.

Nội dung được tổ chức theo từng bài học nhỏ, mỗi bài tập trung vào một câu hỏi lớn, mental model, ví dụ thực tế, sơ đồ và checklist thay vì gom toàn bộ lý thuyết vào một file khổng lồ.

Xem lộ trình tại [`docs/index.md`](docs/index.md).
